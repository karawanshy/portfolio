# Responsive Design

Use when adapting portfolio UI across viewport sizes.

## Process

1. Understand what visual relationship makes the desktop composition work.
2. Preserve that relationship where practical on smaller screens.
3. Recompose when necessary rather than mechanically shrinking everything.
4. Check desktop, tablet, and mobile in the browser.
5. Check text wrapping, overflow, spacing, touch targets, images, and interactive elements.

## Principles

- Mobile should feel intentionally designed, not like collapsed desktop.
- Don't automatically stack every element vertically.
- Prioritize readability and hierarchy over exact desktop geometry.
- Preserve the site's personality without sacrificing usability.
