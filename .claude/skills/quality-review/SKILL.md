# Quality Review

Use for final verification of substantial portfolio work.

## Process

1. Run the project's required automated checks.
2. Exercise the affected experience in the browser.
3. Check navigation, links, controls, and interactions.
4. Check representative desktop, tablet, and mobile sizes.
5. Check keyboard navigation, focus, semantics, contrast, alt text, and reduced motion.
6. Check console/runtime errors and obvious performance problems.
7. Classify findings as BLOCKER, IMPORTANT, or POLISH.

## Principles

- Report what was actually verified.
- Don't report aesthetic preferences as quality defects.
- Don't require premature optimization without evidence of a problem.
- If something could not be verified, say so.
