# Visual Review

Use after visually meaningful implementation or modification.

## Process

1. Open the actual rendered page in the browser.
2. Compare it with the approved design.
3. Inspect the affected section in context with surrounding sections.
4. Check representative desktop, tablet, and mobile sizes.
5. Exercise relevant scroll, hover, cursor, and transition behavior.
6. Record only actionable discrepancies.
7. Classify each as BLOCKER, IMPORTANT, or POLISH.

## Focus

Check:
- hierarchy and composition
- typography and scale
- spacing and positioning
- imagery and layering
- colors, backgrounds, and effects
- motion and interaction
- responsive presentation

Never approve visual work from source-code inspection alone.
